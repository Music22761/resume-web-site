# Sitthikan Chaiyamart — Portfolio

Personal portfolio site built with React + Vite.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # output in dist/
```

- Edit content (projects, skills, contact) in `src/data.js`
- Profile photo: `src/assets/profile.png`
- Résumé PDF for download: `public/Sitthikan-Chaiyamart-Resume.pdf`
